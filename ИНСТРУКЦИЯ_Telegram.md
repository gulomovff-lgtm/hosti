# Запуск приложения в Telegram

Итог: приложение открывается внутри Telegram по кнопке в вашем боте, работает
на любом телефоне, ничего не стоит и не требует сервера.

Файлы уже залиты в репозиторий. Осталось два действия по минуте:
включить GitHub Pages и показать адрес боту.

---

## Что именно вы выкладываете

Папка `dist-static` — это собранный сайт: `index.html`, `app.js` и шрифты с иконками.
Внутри `app.js` лежит не только интерфейс, но и **вся серверная логика приложения** —
те же самые правила бронирования, платёжный контур, антифрод и кабинет владельца,
что и в серверной версии. Они выполняются прямо в браузере Telegram, а данные
хранятся на телефоне.

Что это значит на практике:

- приложение всегда доступно, ничего не падает и не «засыпает»;
- каждый, кто открывает ссылку, видит свою копию данных — брони одного человека
  не видны другому. Для показа инвестору и обкатки интерфейса этого достаточно;
- когда понадобится общая база (гость забронировал — владелец увидел на своём
  телефоне), поднимается серверная версия из папки `hosti`, и в приложении
  меняется одна строка адреса. Ничего переписывать не нужно.

## Шаг 1. Файлы в репозитории — уже сделано

Приложение залито в **github.com/gulomovff-lgtm/hosti**, ветка `main`:
`index.html`, `app.js`, `sw.js`, шрифты, иконки, `manifest.webmanifest`
и `.nojekyll`. Плюс рабочий процесс `.github/workflows/pages.yml`, который
пересобирает сайт при каждом обновлении.

**Обновлять** после правок: пересоберите `npm run build:static`, положите свежий
`Hosti_Telegram_App.zip` рядом с `ЗАЛИТЬ_НА_GITHUB.bat` и запустите его —
скрипт отправит новую версию тем же путём. Требуется установленный Git
([git-scm.com/download/win](https://git-scm.com/download/win)).
Вручную: **Add file → Upload files** → **Commit changes**.

## Шаг 2. Включить GitHub Pages

1. Откройте [настройки Pages](https://github.com/gulomovff-lgtm/hosti/settings/pages).
2. Если вверху уже написано *Your site is live at…* — всё, шаг сделан,
   переходите к боту.
3. Если нет: в блоке *Build and deployment* поставьте Source — **Deploy from a branch**,
   Branch — **main**, папка — **/ (root)** и нажмите **Save**. В этом режиме
   рабочий процесс не нужен — файл `.github/workflows/pages.yml` можно удалить,
   иначе он будет краснеть при каждом обновлении.
4. Подождите одну–две минуты и обновите страницу. Адрес приложения:

   ```
   https://gulomovff-lgtm.github.io/hosti/
   ```

4. Откройте его в браузере телефона — приложение должно запуститься.
   Если видите пустую страницу, подождите ещё минуту: Pages обновляется не сразу.
   Репозиторий должен быть **публичным** — иначе бесплатный Pages не включится.

## Шаг 3. Прицепить приложение к боту

В Telegram откройте [@BotFather](https://t.me/BotFather) и выполните по порядку:

1. `/newapp` — BotFather попросит выбрать бота. Выберите вашего бота Hosti.
2. **Title**: `Hosti`
3. **Description**: `Хостелы Узбекистана по реальной цене — без комиссии`
4. **Photo**: квадратная картинка 640×360 — подойдёт `icon-512.png` из архива
   (BotFather попросит именно 640×360, можно загрузить любой баннер из вашей папки «Соцсети»).
5. **GIF**: пропустите — отправьте `/empty`
6. **Web App URL**: `https://gulomovff-lgtm.github.io/hosti/` — целиком, со слешем на конце.
7. **Short name**: `app` — от него зависит короткая ссылка.

Готово. Приложение открывается двумя способами:

- прямая ссылка: `https://t.me/ВАШ_БОТ/app`
- кнопка меню в чате с ботом: `/mybots` → ваш бот → **Bot Settings** →
  **Menu Button** → **Edit menu button URL** → тот же адрес; текст кнопки —
  `Найти койку`.

Ссылку `https://t.me/ВАШ_БОТ/app` можно отправлять кому угодно: она открывает
приложение прямо в Telegram, без установки.

## Что уже сделано под Telegram

- Вход не спрашивается: приложение узнаёт гостя от Telegram и создаёт аккаунт само.
  Телефон запрашивается один раз — перед первой бронью, потому что он нужен хостелу.
- Кнопка «назад» — системная, в шапке Telegram, а не нарисованная в интерфейсе.
- Окно разворачивается на весь экран, шапка окрашена в фирменный цвет,
  вертикальный свайп не закрывает приложение посреди списка.
- Тактильный отклик на подтверждении брони и на ошибках.
- Диплинки: ссылка `https://t.me/ВАШ_БОТ/app?startapp=hostel_registan` открывает
  сразу карточку конкретного хостела — это то, что вы будете давать в рекламе
  и в QR-кодах на ресепшене.

## Проверка после публикации

1. Откройте `https://t.me/ВАШ_БОТ/app` на телефоне.
2. Пройдите онбординг, найдите койку в Самарканде, забронируйте с взносом.
3. Профиль → Выйти → войдите владельцем (телефоны демо-аккаунтов на экране входа) —
   бронь видна в кабинете, подтверждается в один тап.
4. Вернитесь гостем, отмените бронь — увидите условия возврата.

Если что-то не открывается: в Telegram закройте приложение полностью
(свайп вниз) и откройте заново — клиент кэширует старую версию.

## Про токен бота

Токен, который выдаёт BotFather, — это полный доступ к боту: кто им владеет,
тот может читать переписку бота и писать от его имени. Правила простые:

- **не кладите токен в репозиторий** — GitHub публичный, боты-сканеры находят
  такие токены за минуты;
- автономной версии токен вообще не нужен: в ней нет сервера;
- серверной версии он понадобится только для проверки подписи Telegram и
  задаётся переменной окружения `HOSTI_BOT_TOKEN`, а не в коде;
- если токен где-то засветился — откройте @BotFather, `/revoke`, выберите бота
  и получите новый. Старый перестанет работать мгновенно.

## Когда переходить на серверную версию

Автономная версия не умеет одного: показывать бронь гостя на телефоне владельца.
Как только вам это понадобится (пилот с реальным хостелом), поднимите серверную
версию — инструкция в `ИНСТРУКЦИЯ.md`, а в приложении пропишите адрес сервера:
в `index.html` перед подключением `app.js` добавьте строку

```html
<script>window.HOSTI_API = 'https://адрес-вашего-сервера';</script>
```

и соберите обычную версию командой `npm run build`. Все экраны, правила и тексты
остаются те же — меняется только источник данных.
