# Hosti — приложение для Telegram

Собранная автономная версия приложения бронирования хостелов Hosti.
Открывается как Telegram Mini App или как обычный сайт на телефоне.

**Приложение:** https://gulomovff-lgtm.github.io/hosti/

## Что здесь лежит

| Файл | Что это |
|---|---|
| `index.html` | оболочка приложения |
| `app.js` | приложение целиком: интерфейс **и** серверная логика — правила бронирования, платёжный контур, антифрод, кабинет владельца. Всё выполняется в браузере, данные хранятся на устройстве |
| `sw.js` | сервис-воркер: приложение открывается и без сети |
| `fonts/`, `icon-*.png`, `manifest.webmanifest` | шрифты, иконки, паспорт PWA |
| `ИНСТРУКЦИЯ_Telegram.md` | как подключить к боту и что делать дальше |

Исходники, серверная версия и тесты — в основном проекте (папка `hosti`,
архив `Hosti_MVP_v4.zip`). Пересборка этой папки: `npm run build:static`.

## Важно

Токены ботов, ключи платёжных систем и доступы **не хранятся в этом репозитории**
и не должны сюда попадать: он публичный. Серверная версия читает их из
переменных окружения.
